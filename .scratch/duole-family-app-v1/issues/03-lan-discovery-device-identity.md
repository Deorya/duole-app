## What to build

让 Android App 能在受控局域网发现候选机器人、通过手动地址兜底，并在连接后核对受 TLS
保护的稳定机器人身份和本地可见设备指纹。发现数据只用于列出候选，任何同名、IP 或 mDNS
字段都不能单独建立信任。

## Acceptance criteria

- [x] 机器人仅在 gateway readiness 通过后发布最小、非敏感的 mDNS 候选信息。
- [x] App 发现页展示名称、稳定 ID 提示、地址、API major、网关版本和模式，并能区分同名设备。
- [x] App 支持手动输入 host/port；手动连接执行与自动发现完全相同的 TLS、身份和版本校验。
- [x] 未配对身份端点只返回机器人身份、版本、模式、设备指纹和配对可用性，不泄露状态、事件、地图或家庭数据。
- [x] 用户必须把网络指纹与机器人本地显示/终端指纹核对后才能继续配对。
- [x] App 固定已确认的 robot identity；身份或设备密钥变化时中止连接并给出明确风险提示。
- [x] 伪造 mDNS、DNS/ARP 指向错误设备、同名设备、证书变化和错误 API major 均有自动化或 HIL 测试。
- [x] Android 组播权限、休眠恢复、多网卡和禁用组播路由器下的手动地址降级通过实机验证。

### Agent Brief

#### Current behavior

- 机器人侧已有受 TLS 保护的 App gateway 和真实只读 Device Status 链路，但局域网内没有受控的候选发现广播。
- App 只能使用预先给定的连接参数，尚不能统一处理自动发现与手动地址，也没有持久化的机器人身份信任记录。
- 当前没有刻意收窄的未配对身份查询；发现数据、TLS 对端和稳定机器人身份之间也尚未形成可验证链路。

#### Desired behavior

- gateway readiness 成功后，机器人发布最小 mDNS 候选信息；gateway 停止或失去 readiness 后撤销发布。
- mDNS 字段只帮助用户找到候选，不参与建立信任。名称、地址和发现字段即使被伪造，也不能绕过 TLS、API major、稳定机器人 ID 和设备密钥指纹校验。
- 自动发现与手动 host/port 进入同一连接身份流程。该流程先验证 TLS 对端，再读取未配对身份信息，并确保响应里的身份、版本、模式和指纹与实际 TLS 对端一致。
- 未配对身份响应采用严格 allowlist，只包含稳定机器人 ID、显示名称、产品型号、API/网关版本、运行模式、设备密钥指纹和配对可用性；不得包含设备状态、事件、地图、家庭成员、令牌或其他业务数据。
- 首次信任前，App 展示网络侧指纹并要求用户明确确认它与机器人本地显示或终端输出一致。确认后固定稳定机器人 ID 与设备密钥指纹；后续任一值变化都必须失败关闭并显示风险原因。
- 发现列表用稳定 ID 提示和网络地址区分同名候选，并清晰显示 API major、网关版本和模式。错误 API major 在进入配对前被拒绝。

#### Key interfaces and constraints

- `ConnectionIdentity` 领域边界统一封装候选发现、手动目标、TLS 对端验证、身份查询、首次确认和信任记录；上层页面不自行拼接信任规则。
- 发现发布器只读取非敏感运行身份和公开版本信息，并由公开 gateway 的 readiness 生命周期控制；不得依赖高权限运行时状态或扩大 gateway 权限。
- 设备指纹必须从稳定设备密钥导出，并与当前 TLS 对端使用的密钥绑定；证书或设备密钥不一致时不得把响应中的自报指纹当作可信证据。
- 信任记录至少以稳定机器人 ID 为索引并保存设备密钥指纹；地址变化不改变身份，身份或密钥变化也不能被地址相同掩盖。
- 自动化测试必须覆盖伪造发现字段、同名候选、错误地址命中另一台机器人、证书或密钥变化、身份变化、错误 API major，以及手动地址与自动发现的一致校验路径。

#### Acceptance boundary

- 本次 AFK 开发完成机器人身份端点与受 readiness 控制的发现发布、App 侧统一连接身份逻辑、发现/手动地址界面、信任持久化及可自动执行的回归测试。
- Android 组播权限和生命周期配置纳入代码；真实设备上的组播发现、休眠恢复、多网卡选择、禁用组播路由器下的手动降级，以及本地指纹人工比对保留为 `ready-for-human` 验收。
- Issue 01 和 Issue 02 已提供本次开发所需的软件合同与真实只读链路；其未完成的实机验收不改变本 Issue 的失败关闭规则，也不能在最终交付时被误报为已通过。

#### Out of scope

- 配对码生成/轮换、凭据签发、令牌生命周期和撤销属于后续配对 Issue。
- 远程互联网发现、云端设备目录、跨网段自动穿透、蓝牙配网和路由器配置不在本 Issue 范围。
- 不通过 mDNS 名称、IP、MAC、DNS 结果或用户跳过确认来建立信任，也不提供忽略身份/密钥变化的继续连接开关。
