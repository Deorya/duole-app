# 实现可定制首页与活动事件动态置顶

Status: needs-triage

Type: AFK

User stories covered: 25–31, 43, 163–169

## Parent

[多乐守护 App 与机器人端接入 V1 PRD](../PRD.md)

## What to build

交付多乐守护 Engineering App 的首页信息架构：用户可排序、隐藏和恢复状态、日程、任务等
模块；没有活动事故时安全区保持紧凑，事故发生时临时强制置顶，关闭后恢复原布局。页面采用
安静可信的视觉语气，并落实字体缩放、触控尺寸和非颜色单一表达。

## Acceptance criteria

- [ ] 首页包含连接/同步、安全、视觉监护、电量、当前任务、今日日程和快捷操作的真实摘要。
- [ ] 无活动事故时使用“暂无需处理的安全事件”，不显示“老人平安”等无证据结论。
- [ ] 监护在线、人员可见性和数据更新时间分别展示，不合并成一个安全结论。
- [ ] 用户可拖动排序、显示、隐藏并恢复默认模块；偏好不改变后端权限或 capability。
- [ ] attention/emergency 活动事故覆盖用户排序临时置顶；事故关闭后精确恢复原布局和隐藏设置。
- [ ] stale/offline 状态不会沿用绿色缓存；写快捷操作在同步不连续时禁用并解释。
- [ ] 底部导航固定为首页、现场、日程、机器人、我的，并保留各页状态恢复。
- [ ] 正文支持系统字体放大到 200%，关键触点不小于 48×48 logical pixels。
- [ ] 安全语义同时使用文字、图标和颜色；红色仅用于正在发生的紧急事件。
- [ ] 普通页面支持系统暗色；页面在常见小屏、横竖屏和长文本下无关键内容截断。
- [ ] Android widget/UI 测试覆盖布局持久化、事件插入/关闭、字体缩放、陈旧状态和无障碍语义。
