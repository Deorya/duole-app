# 多乐守护设计系统

Status: `ready-for-human`

设计方向：温暖、安静、可信的家庭守护。它不应像监控软件、医院仪表盘或扫地机器人遥控器；
平时克制，只有真的需要处理时才提高视觉强度。

## 1. 品牌与产品名称

| 项目 | 规范 |
|---|---|
| 中文名 | 多乐守护 |
| 英文名 | DUOLE Family |
| 默认语言 | 简体中文 |
| 品牌语气 | 清楚、克制、尊重，不制造负罪感和虚假安全感 |
| 图标意象 | 可探索“屋檐 + 对话/陪伴”组合，避免盾牌、十字、摄像头眼睛和警笛 |

Engineering V1 可在名称旁显示“工程版”，但不得把工程状态混入品牌 Logo。

## 2. 视觉原则

1. **先给结论，再给证据。** 页面先说“导航暂不可用”，展开后才显示组件和错误码。
2. **正常时少占空间。** 无安全事件时只显示紧凑状态条，不保留大块空事件卡。
3. **异常有层次。** 观察、关注、紧急分别使用信息蓝、琥珀、红，并同时配文字和图标。
4. **控制与浏览分区。** 直播可浏览；进入遥控后切换深色专注界面并持续显示安全条件。
5. **事实不过度推断。** 使用“画面中检测到一人”，不写“老人正在客厅且一切正常”。
6. **危险能力难误触。** 回充、替换任务、权限变更和工程危险动作需要明确确认。
7. **无障碍不是附加项。** 不只靠颜色表达；关键点击目标不小于 48×48 px。

| Token | 主色 | 浅表面建议 | 产品含义 |
|---|---:|---:|---|

| `color.surface.subtle` | `#24312B` |
| `color.text.primary` | `#F4F7F4` |

| `color.border.default` | `#34453C` |
| `color.brand.primary` | `#65B89C` |

红、黄状态在深色主题中需单独校验，不得简单反相。视频上文字使用局部不透明遮罩，避免因
画面内容变化失去对比度。

## 4. 字体与排版

首选 `MiSans Variable`，允许随 App 打包时应由开发团队再次核验所采用字体包的许可文件；
找不到合规字体包时使用平台系统无衬线字体，不从非官方镜像下载字体。

| 样式 | 字号 | 建议字重 | 行高 | 典型用途 |
|---|---:|---:|---:|---|
| `display` | 32 px | 600 | 40 px | 页面关键数值、连接引导标题 |
| `title-lg` | 24 px | 600 | 32 px | 一级页面标题 |
| `title-md` | 20 px | 600 | 28 px | 卡片组标题、弹窗标题 |
| `body-lg` | 17 px | 400/500 | 26 px | 重要正文、按钮 |
| `body` | 15 px | 400 | 23 px | 默认正文、表单 |
| `caption` | 13 px | 400/500 | 19 px | 时间、来源、辅助说明 |

- 支持系统字体缩放到 200%；不用固定高度截断关键文案。
- 数字状态使用等宽数字特性（tabular figures），但不更换成技术感强的等宽字体。
- 中文标题一般不加字间距；英文全大写只用于短状态如 `LIVE`、`REAL`。
- 最多使用 400、500、600、700 四档字重；正文不使用 300 细字。

## 5. 间距、圆角与尺寸

采用 4 px 基线网格：

| Token | 值 | 用途 |
|---|---:|---|
| `space.1` | 4 px | 图标内部微调 |
| `space.2` | 8 px | 紧密元素间距 |
| `space.3` | 12 px | 标签与正文、列表内部 |
| `space.4` | 16 px | 页面水平边距、卡片内边距 |
| `space.6` | 24 px | 分组间距 |
| `space.8` | 32 px | 大区块分隔 |

| Token | 值 |
|---|---:|
| `radius.input` | 8 px |
| `radius.button` | 10 px |
| `radius.card` | 14 px |
| `target.minimum` | 48×48 px |
| `content.maxWidth.phone` | 600 px |

移动端页面默认水平边距 16 px；卡片之间 12 px。大屏手机可增加左右留白，不能无限拉宽文本。

## 6. 图标与图形

- 使用统一圆角线性图标，常规 24 px、描边视觉重量一致。
- 状态图标必须搭配文本：勾选 + “已完成”，警告三角 + “需要关注”。
- 急停用停止八边形或方形，不使用播放/暂停混淆。
- 人员视觉使用中性人形轮廓，不能使用人物照片猜测身份。
- 网络、电池、摄像头、麦克风图标反映可用性，但详细原因仍以文字说明。
- 不以机器人卡通表情替代真实错误状态。

## 7. 核心组件

### 7.1 App Bar 与底部导航

- App Bar 高度随平台规范，标题左对齐；消息入口和连接状态位于右侧。
- 底部固定五项：首页、现场、日程、机器人、我的。
- 每项同时显示图标和文字；选中态使用主色和轻微表面，不只改变图标颜色。
- 活动紧急事件使用全局顶部层，不新增临时底部 Tab。

### 7.2 状态条

用于连接和无活动事件的紧凑表达：高度至少 48 px，包含图标、结论、更新时间和详情入口。

```text
[✓] 暂无需要处理的安全事件       20 秒前 >
```

状态未知时写“安全状态暂不可用”，不能沿用勾选图标。

### 7.3 卡片

- 标准卡片白底、14 px 圆角、1 px 柔和边框；默认不用强阴影。
- 标题、主要事实、更新时间、动作按从上到下排列。
- 一张卡片最多一个主动作；其他动作降为文字按钮或溢出菜单。
- 卡片可以被首页排序和隐藏；连接条与活动安全事件除外。

### 7.4 事件卡

| 等级 | 表面 | 行为 |
|---|---|---|
| 观察中 | 信息蓝左边线/图标 | 紧凑、持续更新 |
| 需要关注 | 琥珀边框和浅底 | 临时置顶，突出“查看详情” |
| 紧急事件 | 红色边框、图标与标题 | 全局置顶；不使用整屏闪烁红色 |

事件结束后以 240 ms 退场，首页模块回到用户保存的位置。

### 7.5 按钮

- 主按钮：实心品牌色；同一视口通常只出现一个。
- 次按钮：描边或轻表面。
- 危险按钮：只有实际不可逆或立即影响安全的动作使用红色。
- “按住喊话”和摇杆使用按压态、触觉反馈和持续状态文字，不能设计成普通点击切换。
- “立即停止”全宽或足够醒目，不因当前控制者不同而隐藏。
- 禁用按钮同时显示不可用原因；不得只降低透明度。

### 7.6 表单

- 标签永久显示在输入框上方，不以 placeholder 代替。
- 错误靠近字段展示，并提供如何修正。
- 时间字段明确标注机器人所在地时区。
- 重复日程用人类可读摘要，如“每周一、三 09:00”，保存前可预览下一次执行。
- 危险删除放在表单底部的独立危险区。

### 7.7 状态阶段器

导航、巡逻、回充统一展示：排队 → 已接受 → 运行中 → 终态。当前阶段高亮，已完成阶段可
回看时间。失败态显示用户说明、稳定错误码和 Engineering V1 的诊断入口。

### 7.8 Toast、Banner 与对话框

- Toast 只用于低风险、无需后续动作的短反馈，如“布局已保存”。
- 可恢复的连接或能力问题使用页面内 Banner。
- 阻断性确认使用对话框，标题必须说清动作，如“结束当前巡逻并回充？”。
- 任务成功不能只通过短暂 Toast 表达，页面状态也必须更新。

### 7.9 空、加载与失败

每个列表至少设计四态：骨架加载、真实空状态、离线缓存、错误。空状态不使用“这里空空如
也”等轻佻文案；应说明原因及可执行下一步。

## 8. 现场与通话组件

### 8.1 直播画布

- 默认 16:9；首帧前显示连接阶段，不显示伪造预览图。
- 左上显示 `LIVE`，旁边显示会话计时；底部显示环境音、延迟、清晰度和隐私状态。
- 冻结后在最后一帧覆盖“画面已冻结 · 1.2 秒前”，并禁用遥控。
- 机器人本地提示状态必须可在 App 查询；提示失败时不开始隐蔽观看。

### 8.2 喊话

- 主文案：“按住喊话”；按下待授权时：“正在取得发声权”；成功时：“松开发送结束”。
- 忙碌时：“A 正在喊话中”，不得静默丢弃音频。
- 按钮释放、手势取消或 App 失焦都结束租约。

### 8.3 通话

- 使用独立“开始通话”按钮。
- 通话栏包含计时、静音、扬声器、摄像头（Family Product）和红色结束按钮。
- 多人宫格按 2、4、9 个位置适配；摄像头关闭显示成员头像与姓名。
- 屏幕不可用降级音频时显示持续 Banner，不用弹窗反复打断。

## 9. 遥控组件

- 专用深色页面，上部保留直播，不能用小画中画替代主要视野。
- 二维摇杆有清晰中点、最大半径与回中动画；仅触点持续存在时发送非零意图。
- 触觉反馈只用于取得控制权、到达边界和被抢占，避免连续震动。
- 顶部固定显示“安全低速”、视频延迟、控制链状态和当前控制者。
- 延迟进入警戒区时先琥珀提示；超过阈值立即停止并锁定，不给“仍要继续”选项。
- 急停与摇杆视觉分离至少 24 px，减少误触；同时保证单手可达。

## 10. 首页个性化

编辑模式提供拖动把手、显示开关和“恢复默认”。保存的是成员自己的顺序：

```text
不可移动：连接与安全状态条
可移动：今日安排 / 现场 / 当前任务 / 快捷操作 / 设备健康 / 最近事件
临时系统层：活动安全事件（不参与排序）
```

隐藏含有未完成动作的模块时，App 提示仍可从对应一级页面访问，但不阻止用户按偏好布局。

## 11. 动效

| Token | 时长 | 用途 |
|---|---:|---|
| `motion.fast` | 160 ms | 按钮、选择、轻量反馈 |
| `motion.standard` | 240 ms | 卡片展开、页面内状态切换 |

- 缓动使用自然的 ease-out；不使用弹跳庆祝安全或照护事件。
- 尊重系统“减少动态效果”。开启后取消位移动画，只保留必要淡入淡出。
- 紧急事件不闪烁；使用稳定颜色、图标、层级和一次触觉/声音提醒。
- 遥控停止是状态立刻改变，不能等待退出动画后才发停止命令。

## 12. 文案规范

### 12.1 推荐写法

| 场景 | 推荐 | 禁止 |
|---|---|---|
| 无事件 | 暂无需要处理的安全事件 | 老人一切安全 |
| 无视觉覆盖 | 当前没有可靠画面 | 未发现老人 |
| 人员观测 | 画面中检测到一人 | 奶奶正在客厅 |
| 命令已收 | 机器人已接受，正在前往客厅 | 已到达客厅 |
| 网络断开 | 与机器人连接中断，已停止遥控 | 网络不好，请稍后 |
| 日程冲突 | 这条日程已在机器人端更新，请刷新后重试 | 保存失败 |
| 本地隐私 | 机器人本地已开启隐私锁，无法远程打开画面 | 摄像头坏了 |
| 任务门禁 | 当前定位不可靠，暂不能开始巡逻 | 操作失败 |

### 12.2 原则

- 使用“机器人”“家属”“照护对象”，不使用“监控对象”“被监护人”。
- 避免“检测正常”“绝对安全”“保证执行”等过度承诺。
- 错误先说明影响，再说明用户能做什么；工程码置于末尾。
- 时间使用绝对时间加相对更新时间，如“10:42 · 20 秒前更新”。
- Family Product 默认不展示概率、ROS 名称、模型名或堆栈。

## 13. 可访问性与设备适配

- 所有关键控件提供语义标签、状态和操作提示，支持 TalkBack/VoiceOver。
- 颜色、图标和文字三者至少使用两种表达状态。
- 屏幕旋转、分屏、来电、锁屏和权限弹窗会立即让遥控回中并释放租约。
- 字体放大时底部导航文字不可消失；复杂表单改为纵向流，不横向压缩。
- 视频宫格允许固定比例裁切，但人物头像不能被强制拉伸。
- Android 系统返回在喊话/遥控中先触发安全释放，再离开页面。

## 14. 设计交付清单

Windows 设计与客户端团队在实现前至少产出：

- Light/Dark 令牌文件和字体许可记录；
- 五个主 Tab 的正常、加载、空、离线、错误状态；
- 活动安全事件三等级与恢复布局动效；
- 现场首帧、直播、冻结、隐私关闭、音频降级状态；
- 喊话空闲/请求/占用/发声/释放状态；
- 遥控进入、持有、停止、未确认停止和抢占状态；
- 日程新增/编辑/冲突/删除及定时巡逻表单；
- 字体 200%、TalkBack、深色模式和小屏手机检查结果。

本文件定义设计约束，不包含本轮交付的视觉稿或可点击原型。
