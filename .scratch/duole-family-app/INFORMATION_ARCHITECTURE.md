# 多乐守护信息架构与页面规格

Status: `ready-for-human`

## 1. 导航模型

家庭产品与 Engineering V1 共用五个一级入口，减少后续重写：

| 标签 | 主要任务 | Engineering V1 | Family Product |
|---|---|---|---|
| 首页 | 快速判断当前是否有事、进入高频任务 | 完整 | 完整，可按成员同步布局 |
| 现场 | 直播、环境音、喊话、通话、遥控 | 单手机 | 多人观看、九方通话 |
| 日程 | 日程与定时巡逻 | 完整 CRUD | 加家庭通知与权限 |
| 机器人 | 地图、导航、巡逻、回充、设备状态 | 完整 | 隐藏工程字段 |
| 我的 | 配对、设置、隐私、记录 | 增加工程模式 | 成员、权限、通知、审计 |

全局消息入口位于页面右上角，不长期占用底部标签。活动紧急事件通过全局覆盖层置顶，不能
因用户重排首页而消失。

## 3. 首页

### 3.1 默认模块顺序

1. 连接与安全状态条；
2. 今日待办与下一条提醒；
3. 现场快捷入口；
4. 当前机器人任务；
5. 快捷操作：停止、房间、巡逻、回充；
6. 设备健康摘要；
7. 最近事件。

用户可以重排、隐藏和恢复默认。连接状态条不得隐藏；活动安全事件不属于普通模块，始终
临时插入顶部。

### 3.2 正常首页线框

```text
┌──────────────────────────┐
│ 多乐守护      工程机 01  ● │
│ 暂无需要处理的安全事件     │  <- 紧凑状态条
│ 监护正常 · 20 秒前更新      │
├──────────────────────────┤
│ 今日安排                 > │
│ 09:00 服药      已完成      │
│ 14:30 复诊提醒   待提醒      │
├──────────────────────────┤
│ 现场                     > │
│ [查看现场]  画面中检测到一人 │
├──────────────────────────┤
│ 当前任务                   │
│ 客厅巡逻 · 第 2/4 点         │
│ [停止]          [查看地图]   │
├──────────────────────────┤
│ 机器人  电量 63% · 导航正常   │
└──────────────────────────┘
 首页   现场   日程   机器人   我的
```

Engineering V1 将“照护对象”位置显示为机器人名称；家庭产品显示照护对象昵称，但不能把
视觉检测结果自动归属于该昵称。

### 3.3 活动事件覆盖

```text
┌──────────────────────────┐
│ 紧急事件                  │
│ 疑似跌倒确认失败            │
│ 10:42 · 机器人正在持续确认   │
│ [查看详情]                 │
└──────────────────────────┘
```

- 紧急事件使用红色语义，但不让整个首页常驻红底。
- `观察中` 用中性/蓝色，`需要关注` 用琥珀色，`紧急事件` 用红色。
- 概率值不作为标题；工程模式可以查看原始诊断，但必须标记“不可直接作为产品结论”。

## 4. 现场

### 4.1 页面层级

1. 全宽直播画面；
2. 连接、清晰度、延迟、环境音和本地隐私状态；
3. 喊话与通话；
4. 手动遥控入口；
5. 结束现场。

### 4.2 现场线框

```text
┌──────────────────────────┐
│ < 现场       LIVE · 00:48 │
│                          │
│       实时画面 16:9        │
│                          │
│ 环境音已开启 · 延迟 286 ms   │
├──────────────────────────┤
│ [ 按住喊话 ]   [ 开始通话 ] │
│                          │
│ [ 进入手动遥控 ]            │
│                          │
│ 机器人端正在显示远程连接提示  │
└──────────────────────────┘
```

- 点击 App 返回键或系统手势不能静默保留发声权。
- 画面冻结、音频失败和连接降级均显示明确原因与重试，不无限转圈。
- Engineering V1 不显示截图、录制、分享和九宫格按钮。

### 4.3 手动遥控线框

```text
┌──────────────────────────┐
│ < 手动遥控    安全低速      │
│      实时画面 + 延迟         │
├──────────────────────────┤
│         ▲                │
│      ◀  ●  ▶             │  <- 持续按压二维摇杆
│         ▼                │
│                          │
│ [      立即停止       ]    │
│ 松手即停 · 当前控制者：你     │
└──────────────────────────┘
```

- 遥控页固定深色，减少画面反光并突出危险控制。
- “立即停止”与摇杆保持足够距离，避免误触，但始终在单手可达区域。
- 延迟超过门槛、视频陈旧、App 后台、锁屏、来电或系统失焦时立刻退出遥控态。
- App 只发送归一化意图，不展示或允许修改真实速度上限。

## 5. 日程

### 5.1 列表与日历

- 默认打开“今天”，按照护对象家庭时区排序。
- 顶部可切换日历和列表，但不同时堆叠两套复杂视图。
- 每条日程显示时间、标题、重复规则、播报/确认状态和来源。
- 来源示例：机器人语音、工程师 App、家庭成员姓名。

### 5.2 日程状态

| 状态 | 展示文案 | 颜色 |
|---|---|---|
| `scheduled` | 待提醒 | 中性 |
| `delivered` | 已播报 | 信息蓝 |
| `snoozed` | 稍后提醒 | 琥珀 |
| `completed` | 已完成 | 正常绿 |
| `skipped` | 已跳过 | 次级灰 |
| `unconfirmed` | 尚未确认 | 琥珀 |
| `delivery_failed` | 播报失败 | 红色，但不称安全事件 |

### 5.3 新增/编辑表单

字段顺序：标题、日期时间、重复、是否需要确认、重试/升级策略、启用状态、备注。删除使用
底部危险区并要求确认。编辑时携带 revision；若语音端已修改，提示刷新和差异，禁止覆盖。

### 5.4 定时巡逻

作为日程内的独立任务类型，字段包括：路线、开始时间、重复、有限轮次、启用状态。页面
明确显示“到点仍需通过机器人安全检查”，不能使用“保证执行”等文案。

## 6. 机器人

### 6.1 地图页

地图是任务状态面，不是底层建图工具。默认显示：

- 地图版本和更新时间；
- 机器人当前位置与朝向；
- 充电桩；
- 已验证房间；
- 当前任务路线、目标与进度；
- 定位陈旧、地图不匹配和任务故障提示。

App 不开放墙体、禁行区、充电桩位姿和导航参数编辑。房间改名只修改展示 label，稳定
`room_id` 不变。

### 6.2 任务操作

| 操作 | 交互 |
|---|---|
| 前往房间 | 选择已验证房间，确认后创建任务 |
| 巡逻 | 选择路线和有限轮次，创建任务 |
| 回充 | 显示当前电量与活动任务，二次确认 |
| 停止 | 立即发送幂等停止，不要求先打开任务详情 |

所有任务详情共用同一阶段组件：排队、已接受、运行中、已完成、失败、已取消。失败必须显示
稳定错误码的用户文案和工程模式入口，而不是只显示“失败”。

### 6.3 设备状态

家庭视图按“受影响能力”组织，而不是按进程名组织：

- 电源与充电；
- 网络与网关；
- 语音交互；
- 视觉与跌倒监护；
- 导航与定位；
- 当前任务；
- 软件版本。

每组先给一句可理解结论，再允许展开工程原因。家庭构建不展示 ROS node、topic、QoS 或
Python traceback。

## 7. 我的

### 7.1 Engineering V1

- 工程师显示名；
- 已配对机器人和取消配对；
- 首页布局、主题、字体和通知偏好；
- 视觉隐私状态和连接记录；
- 关于与版本；
- 工程模式入口。

### 7.2 Family Product

增加家庭成员、身份、细粒度权限、紧急联系人、通知策略、记录保留、账号与生物识别。
管理员人数不受限制；管理员功能权限仍逐项配置。

## 8. 工程模式

工程模式使用独立视觉标识，并常驻 `ENGINEERING BUILD` 水印。功能包括：

- 机器人和网关版本、运行模式；
- 能力原始状态与用户状态并排比较；
- WebSocket 连接、游标、重连和事件计数；
- 最近命令 request ID、job ID、阶段和错误；
- WebRTC 编码、帧率、码率、丢包、抖动、端到端延迟；
- 遥控 watchdog、最后序列、零速确认；
- 导出脱敏诊断包。

工程模式不得提供任意 shell、任意 ROS topic 发布或绕过安全门的开关。

## 9. 全局状态与错误页面

| 场景 | UI 行为 |
|---|---|
| 首次加载 | 显示骨架屏，并标注正在连接的机器人 |
| 无机器人 | 进入发现/手动 IP，不显示空首页 |
| 网关离线 | 保留最后快照但整体标为“非实时”，禁用写操作 |
| 数据陈旧 | 在具体模块显示更新时间和陈旧原因 |
| 权限不足 | 解释缺少的权限，不伪装为设备故障 |
| 能力不存在 | 隐藏或禁用并说明当前版本不支持 |
| mock 模式 | 全局醒目横幅 `无运动模拟` |
| 本地隐私锁 | 结束直播与遥控，显示“需在机器人本地解除” |
| 安全抢占 | 关闭普通操作，展示被哪个事件抑制 |
| 版本不兼容 | 阻止写命令，允许查看诊断与升级说明 |

## 10. 文案规则

### 使用

- “暂无需要处理的安全事件”
- “画面中检测到一人”
- “我现在能看到画面，但定位未就绪，因此无法遥控”
- “命令已接受，机器人正在前往客厅”
- “视觉监护被机器人本地关闭，无法远程开启”

### 禁止

- “老人一切安全”
- “已联系成功”（只有请求发出时）
- “机器人已到达”（只有 goal accepted 时）
- “跌倒检测正常”（视觉关闭或链路异常时）
- “找到了老人”（只检测到未知人员时）
- “连接中……”无限持续且无超时/原因
