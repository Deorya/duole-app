# 分类标签

工程技能使用五种标准分类角色。下表将这些角色映射到本仓库实际使用的状态名称。

| 标准角色 | 本仓库状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由智能体独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或确认 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到某种分类角色时，使用表中对应的本仓库状态名称。
